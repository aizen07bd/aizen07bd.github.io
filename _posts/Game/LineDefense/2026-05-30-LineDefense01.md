# 균열 방어선 개발기 1편: 무료 웹 디펜스 게임 소개와 기본 플레이

> 이 글은 모바일 세로 화면 기준으로 만든 무료 웹 디펜스 게임 **균열 방어선**을 소개하는 개발기 첫 번째 글입니다.  
> 플레이 링크: <https://crackdefenseline.vercel.app>

## 시작하며

이번에 공개한 **균열 방어선**은 설치 없이 브라우저에서 바로 플레이할 수 있는 2D 디펜스 게임입니다. 스마트폰 세로 화면에 맞춰 만들었고, 한 손으로 짧게 켜서 진행할 수 있는 구조를 목표로 잡았습니다.

게임의 기본 상황은 단순합니다. 화면 위쪽에서 몬스터가 아래로 몰려오고, 플레이어 진영은 바리케이트 뒤에서 적을 막습니다. 캐릭터는 자동으로 공격하고, 플레이어는 전투 중 등장하는 보상 카드와 캐릭터 선택을 통해 성장 방향을 정합니다.

개발 초기에는 복잡한 조작보다는 "보면서 선택하는 디펜스"에 가까운 게임을 만들고 싶었습니다. 그래서 이동 조작, 조준 조작, 스킬 버튼을 전부 줄이고, 대신 전투 흐름과 성장 선택에 집중했습니다.

## 게임 한 줄 소개

**균열 방어선은 판타지 세계와 현대 세계를 오가며 하나의 길을 막아내는 모바일 웹 자동 디펜스 게임입니다.**

게임 안에는 판타지 맵과 현대 맵이 함께 등장합니다. 숲, 사막, 정글, 추운지방, 용암던전 같은 판타지 지역이 있고, 학교, 주택가, 도로, 아파트, 한강 같은 현대 지역도 있습니다. 두 세계에 동시에 생긴 균열을 막기 위해 각 세계의 캐릭터들이 합류한다는 설정입니다.

플레이어는 시작할 캐릭터를 고르고, 이후 스테이지를 클리어하면서 동료를 만나고, 보상 카드를 골라 파티를 강화하게 됩니다.

## 왜 웹게임으로 만들었나

처음부터 목표는 "누구나 링크만 누르면 바로 해볼 수 있는 게임"이었습니다.

요즘은 짧은 프로토타입을 공유할 때도 설치 파일이 있으면 플레이 장벽이 생깁니다. 압축 파일을 받고, 압축을 풀고, 실행 파일을 열어야 하는 과정에서 이미 많은 사람이 이탈합니다. 그래서 이번 게임은 정적 웹게임 형태로 만들었습니다.

별도의 회원 가입이나 설치 과정 없이 플레이 링크에 접속하면 바로 시작할 수 있습니다.

이 방식은 개발자 입장에서도 장점이 있습니다. 게임을 수정한 뒤 배포하면 사용자는 같은 주소로 최신 버전을 확인할 수 있고, 피드백을 받을 때도 "이 링크에서 해보세요"라고 말하면 됩니다.

## 기본 화면 구성

균열 방어선은 스마트폰 세로 화면을 기준으로 만들어졌습니다. 화면 구성은 크게 세 부분으로 나뉩니다.

1. 상단: 스테이지, 시간, 몬스터 수, 점수 정보
2. 중앙: 몬스터가 내려오는 전투 구간
3. 하단: 바리케이드와 아군 캐릭터 배치 구간

몬스터는 화면 위쪽에서 등장해 아래쪽 바리케이드를 향해 걸어옵니다. 아군 캐릭터들은 바리케이드 뒤에 서 있고, 사거리 안의 적을 자동으로 공격합니다.

![전투 화면 스크린샷](/assets/img/posts/linedefense-ingame.png)

이 구조를 선택한 이유는 모바일 화면에서 정보를 한눈에 보여주기 위해서입니다. 가로 화면 게임처럼 넓은 시야를 쓰는 대신, 세로 방향으로 "적이 내려온다"는 압박감을 만들고 싶었습니다.

## 기본 플레이 흐름

게임의 한 스테이지는 다음 흐름으로 진행됩니다.

1. 현재 맵과 스테이지가 시작됩니다.
2. 몬스터가 위에서 아래로 몰려옵니다.
3. 아군이 자동으로 가장 가까운 적을 공격합니다.
4. 몬스터가 바리케이드에 닿으면 바리케이드 체력이 감소합니다.
5. 모든 몬스터를 처치하면 보상 카드를 선택합니다.
6. 다음 스테이지로 넘어갑니다.

스테이지 중간에도 일정 처치 수를 달성하면 보상 카드가 등장합니다. 그래서 전투는 완전히 방치하는 구조가 아니라, 중간중간 성장 방향을 선택하는 흐름을 가집니다.

## 바리케이드가 핵심이다

이 게임에서 패배 조건은 크게 두 가지입니다.

첫 번째는 **바리케이드가 파괴되는 것**입니다. 몬스터가 바리케이드에 도달하면 일정 주기로 피해를 입힙니다. 공격력이 충분하지 않거나, 몬스터를 너무 오래 방치하면 바리케이드 체력이 빠르게 줄어듭니다.

두 번째는 **시간 초과**입니다. 제한 시간 안에 전투를 마무리하지 못하고 몬스터가 남아 있으면 게임 오버가 됩니다.

그래서 플레이어는 단순히 공격력만 올릴지, 바리케이드 체력을 보강할지, 공격 속도를 높일지, 관통이나 폭발 효과를 챙길지 계속 고민하게 됩니다.

## 보상 카드 시스템

스테이지를 클리어하거나 일정 처치 수를 달성하면 세 장의 보상 카드 중 하나를 고르게 됩니다.

현재 게임에는 다음과 같은 기본 카드가 들어 있습니다.

| 카드 | 효과 |
| --- | --- |
| 화력 강화 | 기본 피해 증가 |
| 빠른 장전 | 공격 속도 증가 |
| 관통탄 | 탄환 관통 수 증가 |
| 둔화탄 | 명중한 적을 일정 확률로 느리게 만듦 |
| 폭발탄 | 탄환에 범위 피해 추가 |
| 응급 수리 | 바리케이드 체력 회복 |
| 강화 목책 | 바리케이드 최대 체력 증가 |

또한 동료 캐릭터가 합류하면 해당 캐릭터의 스킬 해금 카드도 등장합니다. 스킬을 해금하면 캐릭터가 쿨타임마다 자동으로 강력한 공격을 사용합니다.

## 시작 캐릭터 선택

게임 시작 전에는 6명의 캐릭터 중 하나를 선택할 수 있습니다.

시작 캐릭터에 따라 첫 세계와 동료 합류 흐름이 달라집니다. 판타지 캐릭터로 시작하면 판타지 지역을 먼저 진행하고, 현대 캐릭터로 시작하면 현대 지역을 먼저 진행합니다.

처음 플레이한다면 마법사나 학생 캐릭터 중 하나를 고르는 것을 추천합니다. 마법사는 게임의 판타지 분위기를 가장 잘 보여주고, 학생 캐릭터는 현대 맵에서 시작하기 때문에 설정을 직관적으로 이해하기 좋습니다.

## 자동 전투지만 선택은 남겨두기

균열 방어선의 전투는 자동으로 진행됩니다. 하지만 플레이어가 할 일이 없는 게임은 아닙니다.

플레이어가 직접 조준하지 않는 대신, 다음 선택이 중요해집니다.

- 어떤 캐릭터로 시작할 것인가
- 어떤 보상 카드를 먼저 고를 것인가
- 공격 능력을 강화할 것인가, 생존력을 챙길 것인가
- 새 스킬을 해금할 것인가, 기본 화력을 높일 것인가

이런 선택들이 쌓이면서 같은 게임이라도 매번 조금씩 다른 흐름이 만들어집니다.

## 무료 공개 버전에 대해

현재 균열 방어선은 무료로 플레이할 수 있습니다. 아직 완성형 상용 게임이라기보다는, 웹에서 바로 해볼 수 있는 프로토타입에 가깝습니다.

그래도 기본적인 게임 루프는 들어 있습니다. 캐릭터 선택, 맵 진행, 자동 전투, 보상 카드, 스킬, 컷씬, 엔딩까지 하나의 흐름으로 플레이할 수 있습니다.

이번 공개의 목적은 많은 사람이 직접 플레이해보고, 어떤 부분이 재미있는지 또는 불편한지 확인하는 것입니다.
